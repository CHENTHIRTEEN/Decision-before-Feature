# 边界处理敏感性说明

我们在 `MA-BBOB` 以及相关连续优化实验中，对边界处理方式进行了敏感性分析。原始实现采用简单裁剪（`clip`），即当候选解越过搜索边界时，直接将其截断到最近的可行边界点。随后我们发现，`clip` 会在多个算法中系统性地制造边界堆积（boundary accumulation），并扭曲种群几何量，包括但不限于：`population_overlap`、`centroid_shift`、`covariance_trace` 与 `covariance_effective_rank`。这类效应使得部分行为特征更像是在学习“样本被压到边界上”的伪动态，而非真实的搜索过程。

为此，我们将正式实验的默认边界处理切换为反射式修复（`reflect`）。该策略在越界后将坐标镜像回可行域，能够更好地保留步长方向与搜索动力学，同时显著降低边界点聚集。我们保留 `clip` 作为敏感性分析基线，用于量化边界处理本身对行为特征、几何统计和最终优化性能的影响。我们的对照实验表明，在 `clip` 与 `reflect` 之间，`reflect` 通常能够提高 covariance 的有效秩，并减轻边界堆积带来的结构性扭曲，因此更适合作为正式采集的默认策略。
